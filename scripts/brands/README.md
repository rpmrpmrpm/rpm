# Marks of other music apps

The import window names the apps rpm imports from with their own marks, drawn in one colour like the
Font Awesome icons around them. `scripts/gen_brand_font.py` turns these files into the `rpm Brands`
font. The marks are trademarks of their owners. rpm uses them only to name those apps, and does not
claim any link with them.

| File | Mark | Source |
| --- | --- | --- |
| `applemusic.svg` | Apple Music | [Simple Icons](https://simpleicons.org) 13.21.0, CC0 1.0 |
| `jellyfin.svg` | Jellyfin | [Simple Icons](https://simpleicons.org) 13.21.0, CC0 1.0 |
| `plex.svg` | Plex | The chevron of the Plex app icon, drawn here as one shape |
| `navidrome.svg` | Navidrome | `ui/public/safari-pinned-tab.svg` in [navidrome/navidrome](https://github.com/navidrome/navidrome) |
| `musicbee.svg` | MusicBee | Traced from the dark shapes of the icon on [getmusicbee.com](https://getmusicbee.com) |

All files use one path in one colour. Keep it that way: the font has no colours.
